Добавление новых задач с названием, описанием, датой, приоритетом и статусом.
Редактирование существующих задач.
Удаление выбранных задач.
Сортировка задач по дате выполнения.
Фильтрация задач по приоритету, статусу и просроченности.
Отметка задач как выполненных.
Визуальное отображение просроченных и выполненных задач с разными цветами.

Требования к системе

Операционная система: Windows
.NET Framework / .NET 6 или выше
Visual Studio (2022 или новее)

Инструкция по запуску

Склонируйте репозиторий или скачайте архив с проектом.
Откройте файл решения .sln в Visual Studio.
Соберите проект (Build > Build Solution).
Запустите приложение нажатием F5 или кнопки "Запуск" в Visual Studio.
